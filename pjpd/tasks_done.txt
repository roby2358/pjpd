ID: timestamps-q2jp
Add Created and Updated timestamp properties to tasks and ideas. Each record gets a Created: ISO-8601 timestamp set once at creation, and an Updated: timestamp refreshed on every write. Existing records without timestamps must parse cleanly — treat missing timestamps as absent, not as errors. When an old record is updated for the first time, set Created and Updated to now. This pairs with the backup history idea: timestamps on records plus diffs across bak/ snapshots gives you a full activity picture without any new infrastructure.
